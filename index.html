Activity 1: Designing an E-Commerce Store

Aim

To create a fully operational online shopping website capable of managing products, orders and fulfillment.

Software Required

Shopify or WooCommerce on WordPress. This demonstration website is built using HTML, CSS and JavaScript and can be hosted on GitHub Pages.

Account Creation & Store Setup

  • Create an e-commerce store account.
  • Enter store name and business information.
  • Configure currency and time zone.
  • Configure measurement units.

Adding Products

  • Create product titles and descriptions.
  • Add product prices.
  • Configure SKU and barcode information.
  • Set initial inventory quantities.

Product Categories

  • Create categories such as Fashion and Electronics.
  • Organize products into collections.
  • Display categories in the navigation menu.

Images & Media

  • Upload high-quality product images.
  • Set a primary product image.
  • Add alternative text for accessibility and SEO.

Pricing Configuration

  • Set the active selling price.
  • Set the original/compare-at price.
  • Display discounts and promotional pricing.
  • Configure applicable taxes.

Payment Gateway

  • Configure payment providers.
  • Support card payments and UPI.
  • Provide Cash on Delivery as an option.
  • Test the checkout process.

Shipping & Delivery

  • Define domestic and international shipping zones.
  • Configure flat-rate shipping.
  • Configure free shipping conditions.
  • Display estimated delivery information.

Outcome

A functional e-commerce store interface was developed with product catalog management, category filtering, shopping cart functionality, checkout form, pricing and shipping options.
